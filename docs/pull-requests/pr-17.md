# [PR 17](https://github.com/vig-os/stepv/pull/17) feat: S2–S6 — CLI, limits, Linux + macOS front-ends, release train

## Description

S2–S6: the rest of stepv on top of the S1 kernel (#15). After this PR, the CLI, the Linux
thumbnailer/MIME/KF6 plugin, the viewer window and the macOS Quick Look extensions all work and
are tested, and the release train is wired. Publishing waits only on human credentials (plan.md
§7 "Owed").

## Changes Made

- **S2 CLI** (#5):
  - `--info` (header, cannot fail), `--png` (CPU rasteriser with the broken-face overlay),
    `--glb`, `--mesh`, and `stepv view`
  - one JSON line per run; exit codes 0/2/3/4; cached hits and failures
  - **memory cap** (#4) by child footprint on both platforms
- **S3 limits** (#6): timeout, memory cap and broken inputs, all tested. `just cli-sweep` holds
  the real CLI to its contract over the 401-file corpus.
- **S4 Linux** (#7): `.thumbnailer`, MIME XML (with `model/x-brep`), desktop entry,
  `install.sh`, and a KF6 `ThumbnailCreator`. Tested the way the desktop invokes them.
- **S5 macOS** (#9): Quick Look preview and thumbnail extensions, built without Xcode.
  - The kernel runs **in-process**, because the extension sandbox forbids exec (EPERM). It uses
    the kernel's new C ABI plus `stepv-capi`.
  - The app is 57 MB, with one shared copy of OCCT.
  - Proven through Quick Look itself: all 4 formats thumbnail.
- **S6 release** (#10): version bump on prepare; an AppImage plus a Developer-ID DMG with
  attestations; crates.io via token, then Trusted Publishing; Release asset attachment.
- **NOTICE** (#8): OCCT's LGPL-2.1 and exception, verbatim, in every package.
- **CI** (#11): `kernel.yml` covers both platforms:
  - nix build and `nix flake check`
  - `harness --strict` and the CLI sweep
  - the AppImage and the macOS app
  - Linux desktop integration and cargo-deny advisories
- `justfile.project`'s `test`/`lint` now run the Rust suite. The scaffolded ones ran nothing
  (vig-os/devkit#1811).
- **`deny.toml`** (#13).

Tests: 66 Rust (unit, end-to-end CLI against the real kernel, C ABI), plus the Linux integration
and macOS checks.

Bugs found and fixed along the way, each recorded in its commit:

- a dropped PRODUCT count at the stream tail
- IGES Hollerith fields hidden by record padding
- debug-only integer overflows
- `.gitignore` swallowing `tests/data`
- Scaffold Drift from a hand-edited managed file
- the Quick Look type traps (`public.3d-content`, and the agent's cached type graph)
