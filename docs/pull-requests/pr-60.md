# [PR 60](https://github.com/vig-os/stepv/pull/60) feat(kernel): give healing each face a time budget

Step 3 of #54: a time budget for healing each face, the fix #51 points to.

## Problem

SolidWorks writes no p-curves, so OCCT's transfer-time healing (`FixShape`) has to project every edge onto each face it bounds. On two B-spline ribbon faces of Ultimaker 3 that takes about 25 s each (about 350 ms per edge); their twins on surfaces of the same size take 1 s. One face held up 62,000.

## Change

`kernel/heal.{h,cpp}`:
- stepv registers its own `FixShape` before any reader exists. OCCT keeps whichever operator registers first, and `install_face_budget()` checks that ours won.
- It sets up `ShapeFix_Shape` from the same context parameters, then fixes the faces itself, one at a time, the way `ShapeFix_Shell` and `ShapeFix_Shape` do. The edge tool's projector is replaced by one with a clock.
- Once a face has spent `STEPV_OCCT_FACE_BUDGET_MS` (default 2000) projecting, the next edge throws `stepv::BudgetSpent`. That is deliberately not a `Standard_Failure`, so it abandons the whole fix of that face.
- The face is removed through the shared ReShape context, and then the shell and solid fixes run. This order is required: a face left in its solid without p-curves segfaults inside `ShapeFix_Solid::SolidFromShell`.
- Unhealed faces come back as loose faces beside the healed shape. The mesher draws each one as its outline (`Missing`) without trying the recovery ladder, and the summary counts them in `faces_over_budget`.
- The ladder's own ShapeFix step has the same budget.

**Licence, please check:** stepv is Apache-2.0 and uses OCCT unmodified. I did not copy OCCT's `fixshape` (LGPL). `heal.cpp` sets the same named parameters through the public API from its own table. The parameter names and defaults are OCCT's interface.

## Results

| Ultimaker 3 | before | after |
| --- | ---: | ---: |
| wall | 100.7 s | 42.3 s |
| transfer | 92.2 s | 34.2 s |
| faces over budget | — | 4 |

- 523/523 parts named and coloured, with 62,011 faces.
- All 401 corpus files give identical summaries, field for field, against `origin/main`'s kernel, and transfer times are unchanged.
- The file is still over the CLI's 20 s. What's left is OCCT's quadratic wire self-intersection check and ordinary projection; plan.md records both.

## Tests

`tests/heal.rs` uses a new generated fixture, `tests/data/no-pcurves.step`: the bracket assembly written without p-curves.
- The default budget heals everything.
- Budget 0 leaves exactly the two cylinders unhealed and drawn as outlines; every face, name and colour is kept.
- A file that has its p-curves spends nothing.
- A budget value that isn't a number falls back to the default.
