## Changes Made

- **`stepv-occt --serve`** (`kernel/measure.{h,cpp}`, `stepv_occt_serve`): reads the file once, without meshing, then answers one JSON query per line on stdin/stdout. The protocol is at the top of `measure.h`.
  - **`distance`:** `BRepExtrema_DistShapeShape`'s value and witness points, plus `axis_distance` when both entities have an axis line.
  - **`angle`:** between outward plane normals (0–180°), a line and a plane (0–90°), or two lines (acute).
  - **`point`:** the nearest point on an entity, and a face's normal there.
  - **Numbering:** entities are (part, face) or (part, edge), numbered as `--topology` numbers them. The plane normal is the shared `stepv::outward_normal`.
  - **Sandbox:** it runs in the run's sandbox with nothing writable. Its ready line reports the sandbox.
- **`stepv::measure::Server`** (Rust) runs one kernel per file and holds each query, and the initial load, to the run's `Limits`: the wall clock, and the footprint polled every 5 ms.
  - Past either, or when the kernel dies or sends something unparseable, it's killed. The query reports `Timeout`, `MemoryCap` or `Crashed`, and the next query starts a fresh kernel.
  - A refusal (`no such entity`) keeps the kernel running.
- **The viewer** (`src/view/measuring.rs`, `app.rs`):
  - A worker thread owns the server, so neither a query nor the first load blocks a frame.
  - Measure mode takes two picks, faces or edges, then shows distance, axis distance and angle, and draws the witness segment over the view.
  - Its panel sits above Selection.
- **Test hooks:** `STEPV_VIEW_PICK` takes `;`-separated clicks, including model points (`@x,y,z`) projected through the live camera. `STEPV_VIEW_MEASURE=1` starts in measure mode and reports results on stderr.
- **Fixes found on the way:**
  - label buttons drew their glyph left of the button, because of a centred layout job;
  - the diameter sign is now `Ø`, which egui's fonts have (`⌀` rendered as a box).
