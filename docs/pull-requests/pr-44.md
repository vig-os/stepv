# [PR 44](https://github.com/vig-os/stepv/pull/44) feat(view): section caps, fat edges, edges from the triangulation

## Description

#34: section caps and fat edges. A cut model shows its solid cross-section hatched, with holes left open. Edges and sketches are drawn as anti-aliased quads, and the kernel now takes edge points from the mesh's own triangulation.

## Type of Change

- [x] `feat` -- New feature

## Changes Made

- **Caps, by stencil parity** (`src/view/gpu.rs`):
  - After the image, every surface the cut left is drawn again with no colour or depth writes, inverting the stencil. At a pixel of the plane inside a solid, the count is odd.
  - Parity rather than front/back counting, because CAD exports don't orient faces reliably.
  - A quad on the plane, spanning the fit sphere (`cap_quad`), is drawn where the count is odd. It gets its own depth, so anything in front of the cut still hides it, and is hatched at 45° in two neutral greys.
  - Depth is now `Depth24PlusStencil8`. "Cap the cut" in the Section panel turns the cap off.
- **Fat lines:** edges and sketch lines are instanced quads, six vertices per segment, built in the vertex shader.
  - Edges are 1.5 px wide at the display's scale, and sketches a quarter wider.
  - The quads extend past each end, so polylines join. MSAA anti-aliases them.
  - The id pass draws the same quads, so edges are easier to pick.
- **Edges from the triangulation** (`kernel/stepv-occt-core.cpp`, as #31's review asked):
  - An edge's points come from `PolygonOnTriangulation` on an adjacent face, falling back to curve sampling where a face was recovered.
  - Edges therefore lie exactly on the triangles' boundary, and the depth pull drops from 0.0005 to 0.0001.
- **`STEPV_VIEW_SECTION=axis,offset[,flip]`:** opens with the model cut, for the screenshots and the window test.
- **Per-part stencil bits:** each part inverts its own bit, so overlapping parts are capped too: the plate stays filled where the pins pass through it.
- **Picking:** the id pass caps too, so a click on the hatching picks nothing hidden.
- **Faces:** a slope-scaled depth bias, so edges keep their width on tilted and concave corners.
- **Open shells and non-solids** are not capped.
- **Follow-up #43:** exact, per-part caps from a kernel section.
