# [PR 199](https://github.com/vig-os/stepv/pull/199) feat(graph): G7, colours from the graph

Fixes #141

ADR-0001 §2.2 and the G7 row of §6.

## What changed
- **`src/graph/colors.rs`**: `graph::colors(&g)` indexes every `STYLED_ITEM` / `OVER_RIDING_STYLED_ITEM` (simple or complex). `Product::color` is filled by `structure()`. `Colors::parts(&g, &s, p)` gives XCAF's parts of a product: each part's colour, and its faces' `FaceColor`s in the transfer's order (`None` = the part's colour).
- **Rules = XCAF's observed output**, derived black-box from fixtures (ADR §4, no OCCT source read). They are listed in the module doc and the ADR's realised-API note: sRGB→linear; last `.BOTH.`/`.POSITIVE.` usage, else `.NEGATIVE.`; last style in the file wins, overriding or not; no MDGPR needed; part vs face colour via the part's whole shape; the part split per shape definition / related representation; representation styles applied only when the file styles some representation item.
- **The face join without face ids (M5's)**: the kernel's face order is the transfer's, and `Colors::parts` follows it. The test *checks* the join: equal counts, and every kernel mesh vertex inside the joined face's G4 box. Otherwise it compares colour sets and counts the part apart.
- **CI**: `kernel.yml` runs `graph_colors` on nist-pmi + occt-import-js.
- `related_reps` became a shared free function. The fixture builder moved from `graph_fits.rs` to `tests/stepgen/`.

## Results
- Whole corpus (`STEPV_CORPUS`): 389 files, 2768 leaves, 2496 coloured by XCAF, **0 mismatches**.
  - Parts: 2712 joined (91,278 faces, 91,004 box-checked); 111 compared by colour set.
  - 4 leaves are split by XCAF in a way the graph doesn't model (#197); for those, every face's drawn colour is compared.
  - 29 multi-file leaves were skipped and counted.
  - 2 files weren't compared: the kernel exits 86, as in the other gates.
- CI set (nist-pmi + occt-import-js): 88 files, 166 leaves, 0 mismatches.
- 12 fixtures, one per covered case. `a_colour_the_graph_misses_fails_the_gate`: XCAF colours a `SURFACE_STYLE_RENDERING` and the graph doesn't, and the gate fails (#198).

## Tests

- `nix develop -c cargo test graph::`: 48 passed.
- Full `cargo test`, fmt and clippy `-D warnings`: green.

Size: 494 product lines (colors.rs 454, mostly rustdoc). That is over the ~400 guide and under 650.
