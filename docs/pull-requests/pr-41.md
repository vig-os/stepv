# [PR 41](https://github.com/vig-os/stepv/pull/41) ci(view): Linux viewer job on lavapipe, --frames, size budget, packaging

## Description

#32: the viewer's CI and packaging. It adds a `--frames` bench mode that exits, a Linux CI job that runs the viewer for real on lavapipe and Xvfb (with the GPU drivers removed at the end), a binary-size budget, and the Linux tarball's and nix product's runtime libraries.

> **Stacked on #26, #35, #37, #39 and #40 (all unmerged).** **Review only the commits after `d9803c0`** (#40's head). When those merge, I'll rebase onto main.

## Type of Change

- [x] `ci` -- CI/CD pipeline changes
- [x] `feat` -- New feature (`--frames`)
- [x] `build` -- Build system (nix wrapper)

## Changes Made

- **`stepv view --frames N`:** both windows orbit 1° a frame for N frames, exit, and report `"frames": {count, p50_ms, p95_ms}`, the wall-clock intervals. The first interval, which opens the window, is dropped.
- **CI `Viewer (Linux, lavapipe)`** (`kernel.yml`) runs `scripts/test-linux-viewer.sh` (Debian trixie, mesa-vulkan-drivers, Xvfb):
  - the renderer's tests, with an adapter required;
  - real windows. Xvfb presents them, so whole-window screenshots are required (`STEPV_VIEW_REQUIRE_WINDOW`, as #28's review note on #32 asked);
  - `--frames 30` on every fixture, asserting a GPU backend;
  - the 24 MB size budget;
  - **no GPU at all:** the Vulkan ICDs, EGL vendor files and DRI drivers are deleted, and `--frames 5` must report `software` with the "no usable GPU adapter" note.
- **macOS lane:** the Metal step adds the `--frames` smoke test (inside `test-viewer.sh`) and the 16 MB budget.
- **`scripts/check-size.sh`:** measures a stripped copy against the budget.
- **Linux tarball:** the launcher's comment documents the ours-then-host library order and its consequence. The viewer's dlopened window and GPU libraries come from the host and load against our glibc; one that needs a newer glibc fails to load, and the viewer falls back. `test-linux-tarball.sh` now checks that `stepv view` exits cleanly (exit 3, with its JSON line) in the display-less distro containers.
- **nix:** on Linux the product wraps `bin/stepv` with `LD_LIBRARY_PATH` for vulkan-loader, libGL, libxkbcommon, Wayland and the X11 libraries. CI prints the closure size and holds it to 1.5 GiB.
- **`cargo deny`:** bans, licenses and sources already run over the whole tree in `nix flake check` (all features), and advisories in their own step.
