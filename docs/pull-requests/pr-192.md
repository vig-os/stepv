# [PR 192](https://github.com/vig-os/stepv/pull/192) feat(view): G6b, meshes replace placeholders

Fixes #139

ADR-0001 §3 and the G6b row of §6, building on G6a (#185).

## What changed
- **No placeholder outlives the scene** (`src/view/placeholder.rs`). `Placeholders::replace` drops each leaf the kernel meshed. `Placeholders::done` then drops the rest and counts them in the status line: `graph: 3 parts, 1 without geometry`. `GraphState::scene` runs both and updates the status, so the Viewer's leftover-box field and its upload are gone (`src/view/app.rs`).
- **Tree mismatch: the kernel's tree wins.** `replace` compares the kernel tree's leaf count (`parts_per_leaf`) with the graph's. When they differ, no box maps: all are dropped and counted, as `…; the kernel's tree has 5 parts: 3 placeholders dropped`.
- **`OutlineArtifact::boxes` is filled** by a complete run of a STEP file when every leaf has a box and the leaf counts agree; otherwise it stays absent. The viewer's graph thread hands its boxes to the run. A cached CLI run reads the graph on a thread beside the kernel. Both go through `view::placeholder::load`, via a shared panic-safe `graph_load` in `src/main.rs`.
- **New fixture `tests/data/multifile-nested/`** (from `kernel/fixture-gen.cpp`; only these files were regenerated): the bracket inline, beside a part whose file `pins.stp` is itself an assembly of two pins. The graph sees 4 leaves (3 boxes), OCCT 5. OCCT's multi-file writer keeps assemblies in the main file, so fixture-gen overwrites `pins.stp` after the write.
- The ADR gains G6b's notes; CHANGELOG.

## #186
Closes **items 1 and 2** of #186 (the leaf-count check; leaves without a mesh after `Done`). Items 3–4 are left alone.

## Tests

- `tests/view.rs`
  - `after_done_no_placeholder_remains_on_a_matching_tree`: the bracket, then the same tree with the second pin's leaf as the kernel writes a leaf without geometry.
  - `a_multi_file_tree_mismatch_drops_the_placeholders_and_says_so`
- `tests/cache.rs`
  - `a_complete_run_stores_a_box_per_leaf`: length equals `leaves`, and the boxes equal the graph's.
  - `the_artifact_has_no_boxes_when_a_leaf_has_none`: `multifile/` is all `Unknown`; `multifile-nested/` is a mismatch.
  - `a_complete_view_adds_the_box` (window session) also checks the view path's boxes.
