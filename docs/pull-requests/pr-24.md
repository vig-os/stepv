# [PR 24](https://github.com/vig-os/stepv/pull/24) fix(macos): preview opens face-on, scroll zooms, readable info

## Description

Fixes the three Quick Look preview bugs in #20:

- **Flat parts and sketches open face-on.** Before, a planar part or a 2D drawing was seen nearly edge-on from the fixed isometric angle.
- **The scroll wheel zooms.** Before, it panned the view.
- **The info text is readable.** Before, it was `secondaryLabelColor` on a fixed light-grey scene, which turned light grey in dark mode.

The view now comes from one place, `render::Camera::for_scene`. A PCA plane fit decides whether the model is flat; if it is, the camera looks along the plane's normal. Every front-end uses that function: `stepv --png`, the Quick Look thumbnail (`stepv_render_png`), the preview (the new `stepv_view_angles` gives its angles to Swift), and `stepv view`.

## Changes Made

- `src/render.rs`: `Camera::for_scene` and `Camera::looking_along`, with a Jacobi eigensolver for the plane fit (`f714667`). `stepv --png` uses it.
- `capi`: `stepv_render_png` renders from `for_scene`. The new `stepv_view_angles(mesh, len, &az, &el)` is documented in `stepv.h` with the direction convention, and unit-tested.
- `macos/Shared/StepvSceneBuilder.swift`:
  - `viewAngles(_:)` returns the renderer's angles.
  - `camera(for:azimuthDeg:elevationDeg:)` builds an orthographic camera that frames the bounding sphere. Its up vector is `render.rs`'s `view()` inverted, `(sin a sin e, cos e, -cos a sin e)`, which stays defined straight overhead, where the world's Y would make `look(at:)` degenerate.
- `macos/Preview/PreviewViewController.swift`:
  - uses that camera, with the camera controller's orbit target at the model's centre;
  - `ZoomingSceneView` overrides `scrollWheel` to scale the orthographic camera (a pinch still zooms through SceneKit);
  - the info text sits on a white 88% rounded panel with near-black text.
- `src/viewer.rs`: `Controls::for_scene` gains a `home` camera. `stepv view` opens on it, and Reset returns to it.
- `macos/Tests/main.swift`: the snapshot uses the preview's own camera.
- `scripts/test-macos.sh` now:
  - snapshots `sketch.step` too, and asserts the circle renders **round** (its pixel bounding box has an aspect within 0.9–1.1, where the old view gave about 2:1), offscreen and through Quick Look itself with `--quicklook`;
  - links `libstepv_capi.a` into the snapshot tool.
- `justfile.project`: `macos-install` stops running stepv extensions. Otherwise they keep serving the old binary for hours, which is how the first manual check still showed an ellipse.
- `plan.md`: the ordered work queue (§5).
