# [PR 39](https://github.com/vig-os/stepv/pull/39) feat(view): the model tree, virtualised: show/hide, isolate, search

## Description

#30: the model tree beside the view in `stepv view`. It's virtualised, and supports show/hide that carries down, isolate, search, and selection in both directions with the view.

> **Stacked on #26, #35 and #37 (all unmerged).** **Review only the commits after `467bf26`** (#37's head). When those merge, I'll rebase onto main.

## Type of Change

- [x] `feat` -- New feature

## Changes Made

- **`src/view/tree.rs` (new):** `Tree` flattens the topology's assembly tree once into preorder rows: name, depth, part, parent, and subtree `end`, so a subtree is the range `i + 1..end`. Without a topology, the tree is a flat list of the mesh's part names.
  - **Per frame**, only what's on screen costs anything:
    - the display list (expanded rows, or search matches with their ancestors) is rebuilt only when expansion or the search changes;
    - each row's shown-leaf count, which gives an assembly its tri-state checkbox in O(1), is recomputed only when visibility changes;
    - `ScrollArea::show_rows` lays out only the visible slice.
  - **The panel:** a search field, Show all and Isolate. Each row has a caret, a tri-state checkbox and a selectable name, and a context menu with Isolate, Hide and Show all.
- **`app.rs`:**
  - **Visibility:** a left Model panel. A new tree generation re-uploads the GPU's per-part bitset and re-renders. Hidden parts aren't drawn or picked, and a selection whose part is hidden is dropped (#29's review asked for this).
  - **Selection:** a tree row selects the whole part (`Pick::part`, face `u32::MAX`). The highlight pass then covers every face of it, and the inspector shows the part. A face picked in the view opens its row's ancestors and scrolls to it.

## Changelog Entry

### Added
- **Model tree** ([#30](https://github.com/vig-os/stepv/issues/30)): the assembly tree beside the view in `stepv view`
  - Show/hide per node, which carries down to every part below; Isolate and Show all; search by name

- **Tree model:**
  - flattening a topology tree in preorder, with its end indices;
  - closed assemblies hide their subtree;
  - hiding propagates down, and counts propagate up (tri-state);
  - isolate;
  - search with ancestors, case- and space-insensitive;

  - the display list is cached;

- **#30's acceptance** (release, M3 Ultra, the ignored `forty_thousand_nodes_stay_under_four_ms`):
  - 40,401 rows cost p50 0.072 ms and p95 0.075 ms of layout and tessellation per frame, against a 4 ms budget.
  - That's a headless frame; egui caches the row galleys between frames. #27's 2.2 ms figure was a whole window frame, GPU painting included.
