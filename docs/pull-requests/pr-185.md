# [PR 185](https://github.com/vig-os/stepv/pull/185) feat(view): G6a, the viewer opens on the graph

Fixes #138

## What
- `stepv view` reads a STEP file's graph in-process, on a thread beside the kernel's run (`Load::Graph`), and shows its tree and a translucent wireframe box per leaf before the mesh arrives (ADR-0001 §2.7, §2.8).
- Placeholders have pipelines of their own (unlit, alpha-blended, no depth write). `gpu::Renderer::plan` lists a frame's draws as `(Pipeline, Geometry)`, and `render_with` encodes exactly that list, so a test can check structurally that no placeholder is drawn with the shaded pipeline.
- A leaf with an `Unknown` box gets no placeholder and is counted in the status line (`graph: 1,234 parts, 12 without a box`).
- On `Done`, each leaf's mesh replaces its box, joined by leaf number (`topology::parts_per_leaf`, moved here from two tests).
- A file the graph refuses opens as before, with `graph refused: <reason>` in the status line.
- The ADR's §2.4 gets the realised G6a API and §2.7 the measurement.

## Measured (§2.7: first placeholder frame ≤ 1.5 s)
Ultimaker 3 (release build, sage, warm cache, 3 runs): **0.85–0.89 s** from open, 523 of 523 leaves boxed. Stress assembly: 0.63 s.

## Tests
- `tests/view.rs` (headless):
  - the first frame has placeholders before Done;
  - no placeholder is drawn with the shaded pipeline (checked on the plan);
  - placeholders are replaced by leaf number (the bracket: plate, plus the pin instanced twice);
  - a refused graph (a `REFERENCE` section) says why, and the kernel's run is unchanged.
- `tests/cache.rs` window tests (run by `just view-test`):
  - placeholders come before the scene;
  - a refused graph opens with the reason in the status line.
- `cargo test --test view` exit 0; `cargo test graph::` exit 0; full local gate exit 0. Before the change, the new tests don't compile (E0432/E0599).

## Size
Whitespace-insensitive, unit tests excluded: +654 / −78 product lines (net 576). About 34 of the added lines are `parts_per_leaf` moved from two tests, and about 30 are the moved render-pass setup.
