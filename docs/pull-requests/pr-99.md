# [PR 99](https://github.com/vig-os/stepv/pull/99) feat(view): keep the tree when the run fails, and say why (#89, closes #63)

Closes #89
Closes #63

## What

A `stepv view` load that ends badly no longer closes the window. The window stays open on the tree it has: the cached outline artifact's, or the run's `Event::Tree`. With neither, the tree panel says "No outline". The centre says "The model could not be shown", gives the reason, and adds "The tree is the file's outline; there is no geometry."

**The reason comes from the CLI's own mapping, not a parallel one:** `failure()` in `src/main.rs` formats the report's `status`, `error` and, when given, the kernel's `cause`. `view::Load::Failed` carries that string.

| Case | Window message |
|---|---|
| timeout | `timeout: wall-clock cap exceeded` |
| memory cap | `memory-cap: memory cap exceeded` |
| crash | `crashed: kernel crashed (signal Some(11), exit None)` |
| kernel failure | `failed: <error> (cause: input)` |
| no summary | `error: bad kernel output: the kernel exited without a summary` |

**After the failure:** the window stays idle until the user closes it, and the exit code and report are unchanged. A cancel closes the window itself, so there's nothing left to show.

**Software viewer (#90):** it has no tree, so it keeps today's behaviour: no window opens, and the report says why. This is documented in plan.md.

## Tests (each fails on `origin/main` 1bfce32)

Five window tests, through `Home::view_within` (bounded) and `scripts/test-window-tests.sh`, which now counts 14 and fails unless all of them pass. Each asserts the window's report line `failed: tree N rows, <status>: <error>[ (cause: …)]`, built from the JSON report itself, with the tree's rows and no scene:

- **timeout:** stall hook with `--timeout 5`; the tree comes from the run.
- **memory cap:** balloon hook (512 MiB) with `--memory-mb 64`; the tree comes from the cached artifact.
- **crash:** a kernel that sends itself SIGSEGV.
- **kernel failure, cause `input`:** the throw hook.
- **no summary:** a kernel that exits 0 silently.

On `main` the window shows the loading frame and then closes, without the failure line. `Home::view` now passes `--memory-mb 1024` before the test's own args, so a test can lower it.
